# Smart Clinic Management System – User Stories

## Admin User Stories

As an Admin, I want to securely log in to the system so that I can manage the clinic platform.

As an Admin, I want to add new doctors so that they can start using the system.

As an Admin, I want to update doctor details so that information remains accurate.

As an Admin, I want to remove doctors so that inactive users are not allowed to access the system.

As an Admin, I want to view all registered doctors and patients so that I can monitor system usage.

---

## Doctor User Stories

As a Doctor, I want to securely log in to the system so that I can access my dashboard.

As a Doctor, I want to view my scheduled appointments so that I can plan my consultations.

As a Doctor, I want to view patient details for my appointments so that I can provide better treatment.

As a Doctor, I want to view and update prescription information so that patient medical history is maintained.

As a Doctor, I want to view my availability and daily schedule so that I can manage my working time.

---

## Patient User Stories

As a Patient, I want to securely register and log in so that I can access the clinic services.

As a Patient, I want to search doctors by name and speciality so that I can find suitable doctors.

As a Patient, I want to book an appointment so that I can schedule a consultation.

As a Patient, I want to view my upcoming appointments so that I can manage my visits.

As a Patient, I want to view my prescriptions so that I can track my treatment.
